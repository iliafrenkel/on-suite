# AI access P1 (OAuth + MCP platform, Books read tools) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a household member connect Claude, ChatGPT or Gemini to ON Suite through a remote MCP server at `/mcp`, protected by ON Suite's own OAuth 2.1 authorization server, and ask about their books.

**Architecture:**
- Two new contained platform packages:
  - `internal/platform/oauth` wraps `authelia.com/provider/oauth2`. It owns SQLite storage, `/oauth/*` handlers, the consent page and token verification.
  - `internal/platform/mcp` wraps `github.com/modelcontextprotocol/go-sdk`. It owns `/mcp`, protected-resource metadata, per-grant tool filtering and audit.
- Apps contribute tools through a new optional `app.ToolProvider` interface and never import either library.
- Account and admin management pages are served by the `oauth` package.

**Tech Stack:** Go, SQLite (modernc), `authelia.com/provider/oauth2` v0.4.5, `github.com/modelcontextprotocol/go-sdk` v1.8.0, `github.com/google/jsonschema-go` (already a go-sdk dependency), html/template.

**Spec:** `docs/superpowers/specs/2026-11-24-ai-access-mcp-design.md`

## Global Constraints

- Off by default. Nothing under `/oauth/`, `/mcp`, `/.well-known/oauth-*`, `/account/assistants` or `/admin/ai` is mounted unless `ONSUITE_MCP=on`.
- `ONSUITE_PUBLIC_URL` must be an absolute `https://` URL with no path, query or fragment. Startup fails if MCP is on without it. (The library refuses non-https issuers, so there is no `http://localhost` exception; tests use `https://onsuite.test`.)
- Issuer = public URL. Resource = `<public URL>/mcp`. Both come only from config, never from request headers.
- Grants: `authorization_code` with PKCE S256 and `refresh_token` only. `plain` PKCE is disabled. Public clients only (`token_endpoint_auth_method=none`).
- Lifetimes: auth code 1 min, access token 1 h, refresh token 30 days with rotation on every use. Reuse of a rotated refresh token revokes the whole grant.
- Scopes (exactly these 8, all advertised from P1): `books:read books:write notes:read notes:write reader:read reader:write later:read later:write`. The consent screen ticks reads and leaves writes unticked. A request with no `scope` means all 4 reads.
- Redirect URIs: exact match against `ONSUITE_OAUTH_REDIRECT_URIS` for both DCR and CIMD. Never domain patterns, never loopback.
- Tokens are opaque HMAC. Only signatures are stored.
- No delete tools. Every tool's user ID comes from the verified token, never from arguments.
- Every new third-party import stays in its one package. Arch tests enforce it (Task 11).
- Timestamps through `db.FormatTime`; store tests use a real SQLite file (PATTERNS.md).
- Full check from AGENTS.md stays green on every commit.

## Review Focus

1. **A refresh token sent as a bearer to `/mcp`.** The library's introspection falls back to refresh tokens, so it must be refused with 401. Test in Task 6.
2. **A token whose granted resource isn't `<public URL>/mcp`.** Introspection doesn't check the resource, so it must be refused. Test in Task 6.
3. **A cached CIMD client whose document later changes its `redirect_uris`.** The library's validators run only at fetch time, so the allowlist must also be enforced when a cached client is served. Test in Task 4.
4. **A password reset by the admin or the CLI** must cut off the user's assistants, not only their browser sessions. Test in Task 2.
5. **A consent POST with a scope the client never requested,** for example a hand-edited form adding `books:write`. It must be refused. Test in Task 5.

**Interfaces:**

- All `oauth_*` token tables reference `oauth_grants(id)` with `ON DELETE CASCADE`. `oauth_grants` and `mcp_audit` reference `users(id)` with `ON DELETE CASCADE`. That makes "delete the grant row" the one revocation primitive.

```sql
-- outline; the builder picks indexes
oauth_secrets(name TEXT PRIMARY KEY, value BLOB NOT NULL, created_at TEXT NOT NULL)          -- "hmac", "registration"
oauth_clients(id TEXT PRIMARY KEY, kind TEXT NOT NULL CHECK (kind IN ('dcr','cimd')), name TEXT NOT NULL,
              redirect_uris TEXT NOT NULL, data BLOB NOT NULL, created_at TEXT NOT NULL, last_seen_at TEXT)
oauth_cimd(client_id TEXT PRIMARY KEY, record BLOB NOT NULL, expires_at TEXT NOT NULL)        -- library's CIMD record cache
oauth_grants(id TEXT PRIMARY KEY,               -- the library request ID, stable across code exchange and refresh
             user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
             client_id TEXT NOT NULL, client_name TEXT NOT NULL, redirect_host TEXT NOT NULL,
             requested_scopes TEXT NOT NULL, granted_scopes TEXT NOT NULL,
             created_at TEXT NOT NULL, last_used_at TEXT)
oauth_sessions(signature TEXT PRIMARY KEY, kind TEXT NOT NULL CHECK (kind IN ('code','pkce','access','refresh','registration')),
               grant_id TEXT REFERENCES oauth_grants(id) ON DELETE CASCADE,   -- NULL only for 'registration'
               request_id TEXT NOT NULL, client_id TEXT NOT NULL,
               active INTEGER NOT NULL DEFAULT 1, access_signature TEXT,
               data BLOB NOT NULL, expires_at TEXT NOT NULL)
oauth_pkce_used(client_id TEXT NOT NULL, challenge TEXT NOT NULL, expires_at TEXT NOT NULL, PRIMARY KEY (client_id, challenge))
mcp_audit(id INTEGER PRIMARY KEY, user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
          client_name TEXT NOT NULL, tool TEXT NOT NULL, ok INTEGER NOT NULL, error_kind TEXT NOT NULL DEFAULT '', at TEXT NOT NULL)
```

**Interfaces:**
- Consumes: Task 2's tables.
- Produces:
  - `type Store struct` (unexported fields) and `func NewStore(db *sql.DB, now func() time.Time) *Store`.
  - `*Store` implements every library storage interface listed in the "Library notes" appendix (§Storage).
  - Grant and secret methods:

    - `(*Store) Audit(ctx, AuditEntry) error`
    - `(*Store) RecentAudit(ctx, userID int64, n int) ([]AuditEntry, error)`
    - `(*Store) Sweep(ctx) (int, error)`: deletes expired sessions, PKCE markers and CIMD records, and audit rows older than 90 days.
  - Types:
    - `type Grant struct { ID string; UserID int64; Username string; ClientID, ClientName, RedirectHost string; Requested, Granted []string; CreatedAt time.Time; LastUsedAt time.Time }`

    1. If `scope` is empty, set the form's scope to `ReadScopes` *before* `NewAuthorizeRequest`.

## Library notes (authelia.com/provider/oauth2 v0.4.5)

Verified against the module source. Paths are relative to the module root.

**Provider.**
- `oauth2.Config` is in `config_default.go`. Call `compose.ApplyOAuth21Profile(cfg)` first (`compose/oauth21.go:60`). It enforces PKCE, disables plain PKCE and caps `RefreshTokenMaximumLifespan` at `RefreshTokenLifespan`.
- Strategy: `compose.NewOAuth2HMACStrategy(cfg)`.
- `compose.Compose(cfg, store, strategy, …)` with exactly:
  - `OAuth2AuthorizeExplicitFactory`
  - `OAuth2RefreshTokenGrantFactory`
  - `OAuth2PKCEFactory`
  - `OAuth2TokenRevocationFactory`
  - `OAuth2TokenIntrospectionFactory` (required for `IntrospectToken`)
  - `RFC7591ClientRegistrationFactory`
- Don't use `ComposeAllEnabled`.
- Then call `compose.ValidateOAuth21Profile`.
- Must-set fields:
  - `Issuer`: https, no path or query.
  - `GlobalSecret` and `RFC7591ClientRegistrationGlobalSecret`: each ≥32 bytes and different from each other, or Compose panics.
  - `RefreshTokenScopes: []string{}`: the default requires `offline_access`, or no refresh tokens are issued.
  - `ScopeStrategy: oauth2.ExactScopeStrategy`; the default is wildcard.
  - `ResourceStrategy: oauth2.ExactResourceStrategy`. `DefaultResourceStrategy` is a *prefix* match.

**Storage** (one `*Store` implements all of these):
- `oauth2.Storage` / `ClientManager`. `GetClient` returns `oauth2.ErrNotFound` when missing, which is what triggers CIMD. Assertion-JWT methods can be stubs.
- `hoauth2.CoreStorage`:
  - Invalidated code: `ErrInvalidatedAuthorizeCode` plus the requester.
  - Rotated refresh token: `GetRefreshTokenSession` returns `ErrInactiveToken` plus the requester. That is what triggers family revocation.
  - `RotateRefreshToken`: `ErrNotFound` for an unknown signature.
- `hoauth2.TokenRevocationStorage`: by request ID.
- `pkce.Storage`, including `SetPKCEChallengeUsed`, which is atomic and one-shot.
- `rfc7591.Storage`: registration-token sessions are needed even for open registration.
- `oauth2.ClientIDMetadataDocumentStorage`, passed to `cimd.Config.Storage`.
- `storage.Transactional`: treat as required.
- Persist `session.ExpiresAt`; access-token expiry is read from it.

**Flow.**
- `NewAuthorizeRequest`, then `ar.GrantScope` / `ar.GrantResource`, then `NewAuthorizeResponse(ctx, ar, &oauth2.DefaultSession{Subject})`, then `WriteAuthorizeResponse`.
- `ar.GetID()` is stable through code exchange and refresh, so it is the grant key.
- Token endpoint: `NewAccessRequest(ctx, r, new(oauth2.DefaultSession))`, then `NewAccessResponse`, then `WriteAccessResponse`.
- AS metadata: `NewOAuth2AuthorizationServerMetadata` + `WriteDiscoveryResponse`.
- Revocation: `NewRevocationRequest` + `WriteRevocationResponse`.
- DCR: `NewRFC7591ClientRegistrationRequest` / `Response` / `Write…`.

**Verify.**
- `IntrospectToken(ctx, tok, oauth2.AccessToken, new(oauth2.DefaultSession))`. It **falls back to refresh tokens**, so check `use == oauth2.AccessToken`.
- It **never checks the resource**, so check `req.GetGrantedResource()`.

**Allowlist hooks.**
- **DCR:**
  - Set `RFC7591ClientRegistrationValidators` to `[rfc7591.NewLocalValidator(cfg), allowlist]`. Setting this list drops a default check, so also reject `sector_identifier_uri`.
  - `RFC7591ClientRegistrationMetadataStrategy` forces `TokenEndpointAuthMethod="none"`, clears `Audience`, sets `Resource=[ResourceURL]`, and restricts `Scope` to `AllScopes`.
  - Open registration needs a custom `ClientRegistrationEndpointAuthStrategy` that returns `(nil, nil)` when `id == ""`. The default always demands a bearer.
  - Set `RFC7591ClientRegistrationStrategy = rfc7591.NewDefaultClientRegistrationStrategy()`.
- **CIMD:**
  - `cimd.NewResolver(cimd.Config{…})`.
  - `HTTPClient: oauth2.NewSpecialUseAddressGuardedHTTPClient(...)`. The resolver doesn't add the guard itself.
  - `Validators: [rfc7591.NewLocalMetadataDocumentValidator(cfg), allowlist]`.
  - `TokenEndpointAuthMethods: ["none"]`.
  - The built-in ceiling strips `Resource`, so grant it with a `Strategy` wrapping `DefaultClientStrategy`.
  - Validators run only at fetch time; hence the `GetClient` re-check.
  - CIMD is disabled if `Issuer` is empty.
- **Loopback:** public clients may use registered loopback redirects on any port (`uri.go:127`). The allowlist refuses loopback at registration, so none are ever registered.
