# What's next

## ON Paste

Features:

- Implement keyboard shortcuts
- Expiration on paste snippets
- Password protection for shared paste snippets
- Search and filter on paste snippets
- Ability to create pastes from the command line

Layout:

For wider screens, consider having two columns - one with the list of snippets
and another one for the snippet content.

## ON Notes

Hierarchical note-taking application that allows users to create and organise
notes in a tree-like structure. An outliner. Primary use cases are note
organization and task management. Main concepts:

- Keyboard-driven: navigate and edit notes using keyboard shortcuts
- Ability to zoom in/out on the note tree
- Ability to move notes around in the tree
- Basic markdown support for note content
- The concept of "done" for a note, so that users can mark notes as completed
- Due date for notes

Other features and ideas that need to be fleshed out:

- Sharing: need to think this through; by default, all notes should be private.
- Archiving: notes can be archived to hide them from the main note list.
- Export/import of notes.
